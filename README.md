# 🍽️ 맛집 おかわり

맛집 OKAWARI는 사용자가 모현 맛집을 쉽게 검색하고, 리뷰를 남기고 확인할 수 있는 웹 기반 맛집 정보 서비스입니다.

## 📌 프로젝트 설명
- 사용자가 원하는 음식 종류를 선택하면 맛집 리스트를 보여줍니다.
- 각 맛집에 대한 리뷰와 평점을 확인할 수 있습니다.
- html과 css, js를 사용하여 개발했습니다.

## 🌟 주요 기능
1. 맛집 검색 (지역, 음식 종류 필터)
2. 맛집 상세 정보 확인 (사진, 리뷰, 평점)
3. 사용자 리뷰 작성 및 평점 남기기
4. 본인 리뷰 관리 (수정/삭제)


## 🖥️ 화면 설계서 관리

| **화면 ID** | **화면 이름** | **주요 목적 및 기능** |
| --- | --- | --- |
| `MAIN_01` | **메인 페이지** | 맛집 목록 조회, 카테고리 필터링 및 검색 |
| `RESTAURANT_DETAIL_01` | **맛집 상세 페이지** | 특정 맛집의 상세 정보 및 전체 리뷰 확인, 신규 리뷰 작성 |
| `USER_SIGNUP_01` | **회원가입 페이지** | 신규 사용자의 이메일, 비밀번호, 닉네임 등록 |
| `USER_LOGIN_01` | **로그인 페이지** | 기존 사용자의 서비스 접근 인증 |
| `REVIEW_EDIT_01` | **리뷰 수정 페이지** | 상세페이지서 '수정' 버튼 클릭 시, 기존에 작성했던 리뷰 내용 수정 |
